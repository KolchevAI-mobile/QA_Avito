## Задание 1. Баги на скриншотах

18 дефектов с приоритетами P1-P3: сверка формы редактирования (эталон) с карточкой продавца и карточкой товара. К дефектам вёрстки приложены кропы с красной обводкой. Раздел в [BUGS.md](BUGS.md#задание-1-скриншоты), картинки - в `images`.

## Задание 2.1. API

### Запуск

Нужен JDK 17 или новее и доступ в интернет: Maven и зависимости скачиваются сами.

```bash
./mvnw test
```

Windows:

```powershell
mvnw.cmd test
```

Свой стенд задаётся параметром `-DbaseUrl` или переменной окружения `BASE_URL`:

```bash
./mvnw test -DbaseUrl=https://qa-internship.avito.com
```

### Что внутри

- 74 тест-кейса, 108 автоматических тестов: регистрация, авторизация, матрица доступа к защищённым ручкам, создание и чтение объявления, список продавца, статистика обеих версий, удаление, контракт ответов, нефункциональные проверки.
- Тест-кейсы и привязка к тестам: [TESTCASES.md](TESTCASES.md).
- Найденные дефекты API с шагами и ожидаемым результатом: [BUGS.md](BUGS.md#задание-2-api).

```
src/test/java/ru/avito/internship/
  api/        клиент REST Assured, эндпоинты, модели запроса и ответа
  config/     адрес стенда, лимиты времени
  support/    генераторы данных, база тестов, расширение @KnownBug, общие проверки
  tests/      тесты по ручкам и сквозной сценарий
src/test/resources/
  schemas/    JSON-схемы ответов
```

### Почему часть тестов пропущена

16 из 108 тестов проверяют дефекты стенда: они помечены `@KnownBug("API-01")` и падают ожидаемо. 
В прогоне такие тесты видны как пропущенные с номером дефекта, сборка остаётся зелёной. 
Если дефект исправят, тест пройдёт и сборка упадёт с требованием убрать пометку и обновить BUGS.md.
