# Использованные промпты

## 1. Разведка API

```text
Ты QA, исследуешь незнакомый API по чёрному ящику.
Дано: 8 ручек, все кроме register и autorize требуют Bearer-токен, sellerID должен совпадать с id из токена.
Составь чек-лист проверок по группам: happy path, авторизация (нет токена, битый токен, чужая схема, чужой sellerID), валидация (типы, пустые значения, границы), состояние (после удаления, повторное удаление), контракт (коды ответов, формат ошибок).
Для каждой проверки - ожидаемый результат по контракту.
```

## 2. Тест-кейсы

```text
Преврати чек-лист проверок API в тест-кейсы: ID, шаги, ожидаемый результат.
Собери отдельную таблицу техник тест-дизайна: какая техника где применена. Кейсы, которые отличаются только значением, объединяй в один с набором данных.
Ожидание формулируй через код и поле, а не "работает корректно".
```

## 3. Оформление отчётности

```text
Помоги оформить баг-репорты по описанию расхождений и README к проекту автотестов.
Баг-репорт: где, шаги, факт, ожидаемо, приоритет, окружение; для API ещё и серьёзность. Коротко, без вводных слов.
README: как запустить тесты одной командой, что нужно из окружения, что означают пропущенные тесты.
```

## 4. Строгий «ожидаемый провал»

```text
В JUnit 5 нужна аннотация @KnownBug("API-01"): тест упал - прогон зелёный и тест виден как пропущенный с номером бага; тест прошёл - сборка падает с просьбой снять аннотацию.
Сделай через extension, сами тесты не меняй.
```

## 5. Код тестов

```text
Напиши тест на удаление объявления чужим пользователем.
Предусловия: пользователь A создаёт объявление, пользователь B регистрируется и получает свой токен.
Шаги: B отправляет DELETE /api/2/item/{id} с ID объявления A.
Ожидаемый результат: 403 или 404 (дефект API-01), объявление не удаляется.
```

## 6. Документирование тестов

```text
Добавь к тестам javadoc в одну строку: что делает код и, если это не видно из названия, почему именно так.
Комментируй только неочевидные решения: повторы запросов, обход ограничений стенда, нестандартные фикстуры. DTO, геттеры и простые методы не трогай.
```
